A fractal viewer written in Go and SDL2.

![test](https://i.ibb.co/rfzZpzXT/simplescreenrecorder-2025-08-31-12-54-44-online-video-cutter-com.gif)


It has the following features:
- displays Mandelbrot images in full color
- zoom of up to E-12
- concurrent plot generation (80% reduction in generation time)
- user-configurable display colors, resolution, and styling (can be saved to disk)
- lightweight GUI displaying coordinates on the screen and on the plot

and the following other characteristics:
- from-scratch retained mode GUI components (widgets, scenes)
- custom input handling using an intent system
